*Lifecycle & Lifecycle Methods
-->Basically every component have 3 phases of lifecycle, componentDidMount(), componentDidUpdate(), componentWillUnmount()
-->Constructor(), getDerivedStateFromProps(props, state), render(), componentDidMount()
-->If you want to execute something before the render can use constructor()
-->If the state value is get as prop from another component then use getDerivedStateFromProps(), For example both parent & child have state, but child state is updating based on the parent child then use this method.
-->As usual render() method will call,
-->After that componentDidMount() will trigger, In generally this is used for making API calls, add EventListeners...etc
-->*In second phase component re-renders, And before that the series of methods will execute like getDerivedStateFromProps(), shouldComponentUpdate(), render(), getSnapshotBeforeUpdate(prevStateAsInProps,presentState), componentDidUpdate()
-->We get the update value of state if it's from props
-->Confirmation of component update, By default it's true.
-->As usual component re-render
-->We can get snap nothing but save the changing state before get update
-->Finally once everything done, componentDidUpdate() will executes, In generally if you want to make API call after updated use this phase.
-->The all the above methods should be mention the return anything atleast null, otherwise throw an error.
-->*Finally if you want to remove data from memories, clear the intervals and stop the API calls can do this phase of componentWillUnmount().

*Context API
-->It's core library feature of react,
-->It is used by two more major libraries like react-router-dom, and global state management library redux.This much of importance have the Context API.
-->By using this we can avoid prop drilling in react while passing props to components of entire application.
-->In essentially, for creating contextAPI should use createContext which was at react.
-->It has two components for using one is Provider to maintain the context, Based upon the type of component we are consuming another one is Consumer or useContext() hook.
-->If we are trying to consuming the context non child of provider, it will takes as undefined.
-->If we have multiple Providers in the component, at this time the consumer child component will takes nearest context of the provider.
